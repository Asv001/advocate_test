# ⚖️ Тренажер «Экзамен Адвоката» (PWA)

Это автономное веб-приложение (Progressive Web App - PWA), созданное для подготовки к сдаче квалификационного экзамена на статус адвоката. 

Приложение работает прямо в браузере, **полностью поддерживает работу без интернета (офлайн)** и устанавливается на рабочий стол смартфона (iOS/Android) как нативное приложение.

## ✨ Главные возможности

* **📱 PWA (Офлайн доступ):** Приложение кэшируется на устройстве с помощью Service Worker. Вы можете решать тесты в метро, самолете или за городом без доступа к сети.
* **🧠 Три режима работы:**
  1. **Тренировка:** Работа блоками по 10 вопросов. Мгновенная цветовая подсветка правильных/неправильных ответов.
  2. **Эмуляция экзамена:** Жесткий тайминг (60 минут), 90 случайных вопросов, отсутствие подсказок во время решения.
  3. **Усеченный экзамен:** Возможность прогнать тест по конкретному диапазону вопросов.
* **🔄 Работа над ошибками:** После каждого блока или экзамена система предлагает заново пройти только те вопросы, в которых были допущены ошибки.
* **📊 Сохранение статистики:** Результаты всех сессий (время, процент успеха, режим) сохраняются во внутреннюю память телефона (Local Storage).
* **💾 Умное сохранение:** Возможность поставить тест на паузу, выйти в меню и продолжить сессию позже с того же места.

## 📂 Структура проекта

* `index.html` — Главный файл приложения (разметка, стили и логика JavaScript).
* `questionnaire.yaml` — База данных с вопросами. Легко редактируется в любом текстовом редакторе.
* `sw.js` — Service Worker. Отвечает за кэширование файлов и работу без интернета.
* `manifest.json` — Файл конфигурации PWA (иконки, цвета, отображение на весь экран).
* `js-yaml.min.js` — Локальная библиотека для чтения формата YAML (хранится локально для независимости от CDN).
* `icon-192.png` / `icon-512.png` — Иконки приложения для рабочего стола смартфона (необходимо добавить в корень).

## 🛠 Как установить на iPhone (iOS)

1. Откройте ссылку на проект (через GitHub Pages) в браузере **Safari**.
2. Дождитесь загрузки страницы.
3. Нажмите кнопку **«Поделиться»** (квадрат со стрелочкой вверх внизу экрана).
4. Выберите пункт **«На экран "Домой"»** (Add to Home Screen).
5. Запустите появившееся приложение с рабочего стола. После первого запуска интернет можно отключать.

## 📝 Как добавлять новые вопросы

Вопросы хранятся в файле `questionnaire.yaml`. Чтобы добавить новый вопрос, используйте следующий шаблон:

```yaml
  - task_number: 3
    topic: advocacy_general
    question: >-
      Здесь пишется текст вашего вопроса. Знак ">-" позволяет 
      делать переносы строк, если вопрос очень длинный.
    multiple_choice: false # true, если правильных ответов несколько
    options:
      - Первый вариант ответа
      - Второй вариант ответа
      - Третий вариант ответа
    correct_answers:
      - 2 # Указывается порядковый номер правильного ответа (начиная с 1)
