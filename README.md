# ⚖️ Тренажер «Экзамен Адвоката» (PWA)

Это автономное веб-приложение (Progressive Web App - PWA), созданное для подготовки к сдаче квалификационного экзамена на статус адвоката. 

Приложение работает прямо в браузере, **полностью поддерживает работу без интернета (офлайн)** и устанавливается на рабочий стол смартфона (iOS/Android) как нативное приложение.

## ✨ Главные возможности

* **📱 PWA (Офлайн доступ):** Приложение кэшируется на устройстве с помощью Service Worker. Вы можете решать тесты в метро, самолете или за городом без доступа к сети.
* **🧠 Три режима работы:**
  1. **Тренировка:** Работа блоками по 10 вопросов. Мгновенная цветовая подсветка правильных/неправильных ответов.
  2. **Эмуляция экзамена:** Жесткий тайминг (60 минут), 90 случайных вопросов, отсутствие подсказок во время решения.
  3. **Усеченный экзамен:** Возможность прогнать тест по конкретному диапазону вопросов.
* **🔄 Работа над ошибками:** После каждого блока или экзамена система предлагает заново пройти только те вопросы, в которых были допущены ошибки, а затем бесшовно возвращает к основной тренировке.
* **📊 Сохранение статистики:** Результаты всех сессий (время, процент успеха, режим) сохраняются во внутреннюю память телефона (Local Storage).
* **💾 Умное сохранение:** Возможность поставить тест на паузу, выйти в меню и продолжить сессию позже с того же места.

## 📂 Структура проекта

* `index.html` — Главный файл приложения (разметка, стили и логика JavaScript).
* `questionnaire.yaml` — База данных с вопросами. Легко редактируется в любом текстовом редакторе.
* `sw.js` — Service Worker. Отвечает за кэширование файлов и работу без интернета.
* `manifest.json` — Файл конфигурации PWA (иконки, цвета, отображение на весь экран).
* `js-yaml.min.js` — Локальная библиотека для чтения формата YAML (хранится локально для независимости от CDN).
* `icon-192.png` / `icon-512.png` — Иконки приложения для рабочего стола смартфона.

## 🛠 Как установить на iPhone (iOS)

1. Откройте ссылку на проект (через GitHub Pages) в браузере **Safari**.
2. Дождитесь загрузки страницы.
3. Нажмите кнопку **«Поделиться»** (квадрат со стрелочкой вверх внизу экрана).
4. Выберите пункт **«На экран "Домой"»** (Add to Home Screen).
5. Запустите появившееся приложение с рабочего стола. После первого запуска интернет можно отключать.

## 📝 Как добавлять новые вопросы

Все вопросы хранятся в файле `questionnaire.yaml`. Структура файла строго типизирована. Чтобы добавить новый вопрос, используйте следующий шаблон (учитывайте отступы — для YAML это важно):

``` yaml
  - task_number: 3
    topic: advocacy_general
    question: >-
      Текст вашего вопроса. Символы ">-" позволяют писать длинный текст 
      с переносами строк, при этом программа прочитает его корректно.
    multiple_choice: false 
    options:
      - Первый вариант ответа
      - >-
        Второй вариант ответа
      - Третий вариант ответа
    correct_answers:
      - 2 
```

### Разбор полей:
* `task_number` *(число)* — Порядковый номер вопроса. Используется для навигации, запуска усеченных экзаменов и привязки разбора ошибок.
* `topic` *(строка)* — Тематическая категория вопроса (например: `advocacy_general`, `criminal_process`). 
  * *Примечание:* Сейчас это поле служит для визуального порядка в базе данных, но в будущем позволит добавить в приложение режим «Тренировка по конкретным темам». Пишите топики латиницей без пробелов (используйте нижнее подчеркивание).
* `question` *(строка)* — Непосредственно текст задания.
* `multiple_choice` *(true / false)* — `true`, если правильных ответов несколько. `false`, если ответ только один.
* `options` *(список)* — Варианты ответов. Начинаются с дефиса и пробела. Если внутри текста ответа есть спецсимволы, лучше обернуть всю строку в одинарные кавычки.
* `correct_answers` *(список чисел)* — Указываются **порядковые номера** правильных ответов (начиная с 1). 

**Важно:** Если правильных ответов несколько (указано `multiple_choice: true`), номера ответов перечисляются списком в столбик:

``` yaml
    correct_answers:
      - 1
      - 3
```

### 📌 Список доступных тем для поля `topic`:
Для корректной классификации вопросов используйте строго следующие восемь категорий:

1. `advocacy_general` — Общие положения (понятие, принципы, виды юр. помощи).
2. `attorney_status` — Статус адвоката (присвоение, приостановление, прекращение, присяга).
3. `rights_and_duties` — Права, обязанности, гарантии независимости (кроме запроса).
4. `attorney_request` — Адвокатский запрос (понятие, форма, сроки ответа, ответственность).
5. `advocacy_forms` — Формы адвокатских образований (кабинет, коллегия, бюро, юр. консультация).
6. `advocacy_chambers` — Органы самоуправления (ФПА, АП субъектов, советы, собрания/конференции).
7. `ethics_and_secrecy` — Этика и тайна (адвокатская тайна, конфликт интересов, дисциплинарное производство).
8. `agreements_and_fees` — Соглашения и оплата (заключение соглашений, гонорары, бесплатная юр. помощь).
